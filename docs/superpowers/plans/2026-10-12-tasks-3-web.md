# Taskop Tasks — Part 3: Web App — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let managers run tasks on the web: a `/tasks` page with tabs, filters and cursor pagination; a create/edit dialog (person-or-team picker, due date and time in the tenant's zone, evidence rules, review toggle, instruction photos and videos); a deep-linkable task drawer with submissions, reviews, history, the source problem and the Approve / Reject / Cancel / Edit actions; and the problem → task loop on the problems page and in the schedule drawer's execution tab. Finish with the spec §9 Playwright flow.

**Architecture:**
- **New feature folder `apps/web/src/features/tasks/`**, built like `features/executions/`: React Query hooks in `queries.ts`, pure helpers in `labels.ts` and `task-form.ts`, components that call `api.*` from `@/lib/session`, shadcn/ui components, every string from `az.tasks`.
- **The URL owns the drawer.** `/tasks?task=<id>` opens it. Rows of the task table, the problems page and the execution tab link there, and the create dialog navigates there after saving. The drawer reads `TaskDetail` and trusts its `canManage` / `canReview` (Part 1 decision 22); it never re-implements spec §6.1.
- **Media are private and reuse SP4's viewer.** `MediaThumb` / `MediaLightbox` in `features/executions/media.tsx` get their presigned URL from a context (`MediaUrlSourceProvider`): execution media (default, unchanged), task media (`api.taskMedia.url`) or a task's source-problem media (`api.tasks.problemMediaUrl`). The 4-minute cache and the "fetch once more on load error" rule stay in one place.
- **Instruction media are uploaded after the task exists.** The dialog saves the task (client UUIDv7 id), then per file: `api.tasks.registerMedia` → `PUT uploadUrl` → `api.taskMedia.confirmUploaded`. Media ids are fixed when the file is picked, so a retry re-sends the same registration (idempotent on id) and never creates a second task.
- **Times.** Due dates are typed as a tenant-local date and time and converted with `zonedTimeToUtc` from `@taskop/contracts`, never with the browser's zone. Shown times use `useFormatDateTime` (tenant zone).

**Tech Stack:** React 19.2.3, TanStack Router 1 + Query 5, shadcn/ui (Radix `Tabs`, `Dialog`, `Checkbox`), i18next, lucide-react, Vitest 5 + Testing Library + user-event, Playwright (all already in the repo). **No new packages.**

**Spec:** `docs/superpowers/specs/2026-10-12-tasks-design.md` — this plan implements §8 and the web and Playwright parts of §9. **Interface source:** `docs/superpowers/plans/2026-10-12-tasks-1-api.md`, section *Interfaces for Parts 2 and 3* and its *Spec decisions*; this plan uses only names listed there or already in the repo.

## Global Constraints

- The product name is **Taskop**. Azerbaijani (`az`) is the only locale.
- Every visible string is an i18n key. New web strings go into `az.tasks` (`packages/i18n/src/az/tasks.ts`, Part 1 Task 3's file) as **new keys only**: `page`, `picker`, `dialog`, `drawer`, `problems`. Part 1's keys (`statuses`, `priorities`, `sources`, `resolutions`, `evidenceLevels`, `mediaRoles`, `reviewDecisions`, `historyReasons`, `issues`, `flags`, `alreadyTaken`) are reused, never renamed. `az.nav.tasks` comes from Part 1.
- Install nothing. Use the existing components: `Badge`, `Button`, `Dialog`, `Tabs`, `Table`, `Input`, `Textarea`, `Label`, `Checkbox`, `Alert`, `NativeSelect`, `PageHeader`, `FormError`.
- Tenant time zone: `useMe().tenant.timezone`. Due date + time → instant: `zonedTimeToUtc(date, timeToMinutes(time), tz)`. A due date without a time is **23:59** that day (`END_OF_DAY`). Due-range filters cover whole tenant-local days: `dueFrom` = 00:00 of the first day, `dueTo` = 00:00 of the day after the last day − 1 ms.
- Task list: `GET /tasks` pages of **50**, keyset cursor, "Daha çox göstər" while `nextCursor` is set (as the problems and audit pages do).
- Tabs → query: *Hamısı* `{}`; *Yoxlamamı gözləyir* `{ awaitingMyReview: 'true' }`; *Gecikmiş* `{ overdue: 'true', status: 'new,accepted,in_progress,awaiting_review' }`; *Mənim yaratdıqlarım* `{ createdBy: me.user.id }`. A status filter replaces the tab's status list.
- Menu: "Tapşırıqlar" (`/tasks`) for holders of **`tasks.view` or `tasks.manage`**. As with every page, the route itself is not guarded; `GET /tasks` returns a user's own tasks to anyone (spec §6.2).
- "Yeni tapşırıq", the assignee filter and "Tapşırıq yarat" need **`tasks.manage`** (the picker's `GET /tasks/assignees` is `tasks.manage`-only).
- Instruction media: at most `TASK_LIMITS.instructionMedia` = **5** per task, counting the task's existing instruction media. Types `MEDIA_LIMITS.mimeTypes` (JPEG, PNG, MP4, MOV); photo ≤ 5,242,880 bytes; video ≤ 62,914,560 bytes, ≤ 60 s, short edge ≤ 720. Checked in the browser before anything is sent; the web does not resize or transcode. `source: 'gallery'`, `capturedAt` = the moment the file was picked.
- Media URLs: `MEDIA_URL_FRESH_MS` (240,000 ms) cache and the single refetch on load error apply to task and problem media exactly as to execution media. Pending media never ask for a URL.
- Reject needs a non-empty trimmed comment (≤ `TASK_LIMITS.commentMax` = 1,000); cancel needs a non-empty trimmed reason (≤ 1,000). Title 1–200 after trimming; instructions ≤ 5,000.
- Tests mock `@/lib/session` exactly as the existing feature tests do. No test depends on the real clock or the machine's time zone.
- Commits use `git add <explicit paths>` (never `-A`). Every commit message ends with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (the second `-m`).

## Spec decisions (ambiguities resolved against the real code)

1. **Deep link `/tasks?task=<id>`.** The SP4 pattern for drawers is a validated search param. The task page reads it with `useSearch({ strict: false })` and closes the drawer by navigating to `/tasks` without it.
2. **The table's "source" column is text, not a link.** `TaskSummary` carries `problemId` only, while the problems page has no per-problem URL and the run drawer needs `localDate` + `occurrenceId`. The column shows "Problemdən" / "Birbaşa"; the drawer's problem card links to the run (`/schedule?date&occurrence&tab=execution`).
3. **`NavItem.permission` becomes "any of".** It accepts one key or a list; "Tapşırıqlar" lists `['tasks.view', 'tasks.manage']`, so a custom role with only `tasks.manage` still sees the menu.
4. **"Gecikmiş" means overdue and still open.** `overdue_at` stays on completed tasks (spec §3); a manager's overdue tab lists what still needs doing. A completed-late task is still shown with its "Gecikib" badge in *Hamısı*.
5. **Assignee filter only for `tasks.manage`.** It reuses the dialog's picker (`GET /tasks/assignees`), which `tasks.view`-only holders (auditors) cannot call; for them the filter is not rendered.
6. **Editing sends only changed fields.** A stale form can never overwrite someone else's change, and `assignee` is sent only when a different person or team was picked. For an accepted team task (assignee and team both set) the picker shows the person; picking the team hands the task back to the team (a reassign, spec §3).
7. **A problem task's site is read-only** (create and edit): the API takes it from the problem (Part 1 decision 19), so the dialog shows "Obyekt problemdən götürülür: …" instead of a select and never sends `siteId` for it.
8. **Instruction media after save; failures keep the task.** If an upload fails, the dialog stays open with the task saved, the failed files marked and the button "Faylları yenidən yüklə"; a retry re-registers the same media ids. Closing the dialog then still hands the saved task to the caller (the tasks page opens it in the drawer).
9. **Problem media kind comes from the stored file.** `ProblemDto` has `mediaIds` only (no kind or status). The drawer fetches each id's URL through `api.tasks.problemMediaUrl` and reads photo or video from the URL path's extension (`MEDIA_LIMITS.extensions`: `mp4`, `mov` = video). A medium that cannot be signed (pending or purged) shows "Fayl açılmadı".
10. **"Disabled with a tooltip"** is a disabled button inside a `<span title="…">` (there is no tooltip component and nothing may be installed).
11. **Execution tab:** every problem row shows its resolution badge; it is a link to the drawer when `taskId` is set, plain "Tapşırıq yoxdur" otherwise. **Problems page:** the "Nəticə" column shows the badge-link for problems with a task, "Tapşırıq yarat" for `tasks.manage` holders on problems without one, and "Tapşırıq yoxdur" for everyone else.
12. **Stale drawer:** there is no revision check (Part 1 decision 10). Every action answer replaces the drawer's copy; a `409` (for example `TASK_STATE_INVALID` after the worker resubmitted or another reviewer decided) shows the API message and refetches the task.
13. **UUIDv7 on the web** is a copy of the phone's generator (`apps/mobile/src/offline/ids.ts`) in `apps/web/src/lib/ids.ts`, using `crypto.getRandomValues`; contracts have no shared generator and adding one would change Part 1's package.
14. **The picker is an inline combobox** (input + `role="listbox"` with two `role="group"`s, arrow keys and Enter), not a popover: there is no popover/command component and nothing may be installed.
15. **`features/executions` now imports from `features/tasks`** (the dialog on the problems page, `resolutionVariant` in the answers view). `features/tasks` imports only `media.tsx`, `labels.ts` and `queries.ts` types from executions, so there is no import cycle.

## Review Focus

These are the five input classes most likely to bite real users that no spec test names. Each line gives the task whose test pins it.

1. **A due time typed across the tenant's zone and DST.** A manager in a Berlin-zoned tenant types "09:00" on 2 November from a laptop set to Baku; the task must be due 08:00 UTC (CET), not 05:00 UTC; a summer date must use CEST; a time inside the spring-forward gap must not throw. Pinned in Task 2 (`builds the due instant in the tenant's zone, not the browser's, across DST`) and Task 6 (`creates a task with every field, the due time read in the tenant's zone`).
2. **A stale form or drawer.** The manager opened the edit dialog, the worker started the task meanwhile, and the manager only fixes the title: the save must not reassign (reset to `new`) or overwrite other fields. A reviewer presses Approve on a task another reviewer already decided: the drawer must show the API's message and the task as it is now. Pinned in Task 6 (`sends only what changed: a new title does not reassign; a new assignee does, with a warning`) and Task 7 (`shows the error and the current task when someone changed it meanwhile`).
3. **An upload that fails after the task was created.** The network drops during the PUT of an instruction photo; pressing the button again must not create a second task and must re-send the same media id; closing instead must still open the created task. Pinned in Task 6 (`keeps the created task when an upload fails, and retries only that file with the same id`, `closing after a failed upload still hands over the created task`) and Task 4 (`registers, uploads and confirms each waiting file, and reports failures without stopping`).
4. **Reject without a comment.** An empty or whitespace-only comment must not reach the API (it would come back `VALIDATION_FAILED`); the button stays disabled and the trimmed comment is sent. Pinned in Task 7 (`approves, and rejects only with a comment`).
5. **A user without task rights on `/tasks`.** A worker or auditor follows a link: no "Yeni tapşırıq", no assignee filter, no call to the manage-only picker endpoint, the list the API returns, and a `404` task shown as an error inside the drawer rather than a crash or a blank page. Pinned in Task 8 (`without task rights: no create button or assignee filter; a task it cannot read shows the error in the drawer`).

/**
 * RFC 9562 UUIDv7: 48-bit Unix milliseconds, version 7, variant 10, 74 random bits. Tasks and their media are
 * created with client ids (spec §5), like the phone's executions; this is the phone's generator
 * (apps/mobile/src/offline/ids.ts) with the browser's random source.
 */
export function uuidv7(now: number = Date.now(), random: (byteCount: number) => Uint8Array = (n) => crypto.getRandomValues(new Uint8Array(n))): string {
  const b = new Uint8Array(16);
  let t = Math.floor(now);
  for (let i = 5; i >= 0; i--) {
    b[i] = t % 256;
    t = Math.floor(t / 256);
  }
  const r = random(10);
  b[6] = 0x70 | (r[0]! & 0x0f);
  b[7] = r[1]!;
  b[8] = 0x80 | (r[2]! & 0x3f);
  for (let i = 3; i < 10; i++) b[i + 6] = r[i]!;
  const hex = Array.from(b, (x) => x.toString(16).padStart(2, '0')).join('');
  return `${hex.slice(0, 8)}-${hex.slice(8, 12)}-${hex.slice(12, 16)}-${hex.slice(16, 20)}-${hex.slice(20)}`;
}

export const END_OF_DAY = '23:59';

/** A tenant-local date and time as an instant. Never the browser's zone: the tenant's (spec §8). */
export function dueAtFromLocal(date: string, time: string, timeZone: string): string | null {
  if (!date) return null;
  return zonedTimeToUtc(date, timeToMinutes(time || END_OF_DAY), timeZone).toISOString();
}

/** The reverse of dueAtFromLocal, for the edit form. Seconds are dropped. */
export function localDueParts(iso: string | null, timeZone: string): { date: string; time: string } {
  if (!iso) return { date: '', time: '' };
  const at = new Date(iso);
  const wallMs = at.getTime() + tzOffsetMinutes(timeZone, at) * 60_000;
  return { date: localDateOf(at, timeZone), time: minutesToTime(Math.floor(wallMs / 60_000)) };
}

import { ApiError } from '@taskop/api-client';
import { MEDIA_LIMITS, type MediaKind } from '@taskop/contracts';
import { uuidv7 } from '@/lib/ids';
import { api } from '@/lib/session';

export interface MediaMeta {
  width: number | null;
  height: number | null;
  durationMs: number | null;
}

/** waiting → uploading → done | failed (sent again on the next save). refused: never sent (type, size or no room). */
export type UploadState = 'waiting' | 'uploading' | 'done' | 'failed' | 'refused';

export interface PendingMedia {
  /** Fixed when the file is picked, so a retry re-sends the same registration (idempotent on id). */
  id: string;
  file: File;
  kind: MediaKind;
  meta: MediaMeta;
  capturedAt: string;
  state: UploadState;
  /** An i18n key. */
  error: string | null;
}

export type ReadMediaMeta = (file: File, kind: MediaKind) => Promise<MediaMeta>;

export function mediaKindOfMime(mime: string): MediaKind | null {
  if ((MEDIA_LIMITS.mimeTypes.photo as readonly string[]).includes(mime)) return 'photo';
  if ((MEDIA_LIMITS.mimeTypes.video as readonly string[]).includes(mime)) return 'video';
  return null;
}

/** The API's MEDIA_TOO_LARGE rule (photo ≤ 5 MB; video ≤ 60 MB, ≤ 60 s, short edge ≤ 720), checked before anything is sent. */
export function mediaFileIssue(kind: MediaKind, bytes: number, meta: MediaMeta): string | null {
  if (kind === 'photo') return bytes > MEDIA_LIMITS.photoMaxBytes ? 'tasks.dialog.photoTooLarge' : null;
  const tooLong = (meta.durationMs ?? 0) > MEDIA_LIMITS.videoMaxSeconds * 1000;
  const tooWide = Math.min(meta.width ?? 0, meta.height ?? 0) > MEDIA_LIMITS.videoMaxShortEdge;
  return bytes > MEDIA_LIMITS.videoMaxBytes || tooLong || tooWide ? 'tasks.dialog.videoTooLarge' : null;
}

/** Browser only (jsdom cannot decode): a photo's dimensions, a video's dimensions and length. The web never resizes or transcodes. */
export const readMediaMeta: ReadMediaMeta = async (file, kind) => {
  const url = URL.createObjectURL(file);
  try {
    if (kind === 'photo') {
      const img = new Image();
      img.src = url;
      await img.decode();
      return { width: img.naturalWidth, height: img.naturalHeight, durationMs: null };
    }
    const video = document.createElement('video');
    video.preload = 'metadata';
    await new Promise<void>((resolve, reject) => {
      video.onloadedmetadata = () => resolve();
      video.onerror = () => reject(new Error('metadata'));
      video.src = url;
    });
    return { width: video.videoWidth, height: video.videoHeight, durationMs: Math.round(video.duration * 1000) };
  } finally {
    URL.revokeObjectURL(url);
  }
};

/** Checks picked files in order; at most `room` of them are accepted (TASK_LIMITS.instructionMedia minus what the task has). */
export async function prepareFiles(files: readonly File[], room: number, read: ReadMediaMeta = readMediaMeta): Promise<PendingMedia[]> {
  let left = room;
  const out: PendingMedia[] = [];
  for (const file of files) {
    const kind = mediaKindOfMime(file.type);
    const meta = kind ? await read(file, kind).catch(() => null) : null;
    let error: string | null = kind && meta ? mediaFileIssue(kind, file.size, meta) : 'errors.MEDIA_TYPE_INVALID';
    if (!error && left <= 0) error = 'tasks.dialog.mediaLimit';
    if (!error) left -= 1;
    out.push({
      id: uuidv7(),
      file,
      kind: kind ?? 'photo',
      meta: meta ?? { width: null, height: null, durationMs: null },
      capturedAt: new Date().toISOString(),
      state: error ? 'refused' : 'waiting',
      error,
    });
  }
  return out;
}

/**
 * For each waiting or failed file, in order: POST /tasks/:id/media → PUT the file to the presigned URL (skipped when
 * the medium is already stored) → POST /task-media/:id/uploaded. A failure is recorded and the next file still goes.
 */
export async function uploadInstructionMedia(
  taskId: string,
  items: readonly PendingMedia[],
  onChange: (id: string, patch: Partial<PendingMedia>) => void,
): Promise<number> {
  let failed = 0;
  for (const m of items) {
    if (m.state !== 'waiting' && m.state !== 'failed') continue;
    onChange(m.id, { state: 'uploading', error: null });
    try {
      const ticket = await api.tasks.registerMedia(taskId, {
        id: m.id,
        role: 'instruction',
        kind: m.kind,
        source: 'gallery',
        mime: m.file.type,
        bytes: m.file.size,

import { useId, useState } from 'react';
import { useTranslation } from 'react-i18next';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';
import { Label } from '@/components/ui/label';
import { useDebounced } from '@/features/scheduling/labels';
import { errorText } from '@/lib/errors';
import { cn } from '@/lib/utils';
import type { AssigneeChoice } from './labels';
import { useTaskAssignees } from './queries';

interface Props {
  label: string;
  value: AssigneeChoice | null;
  onChange: (choice: AssigneeChoice | null) => void;
  clearable?: boolean;
}

/** Person-or-team combobox (spec §8): GET /tasks/assignees, people and teams in two groups, searched by name. */
export function AssigneePicker({ label, value, onChange, clearable = false }: Props) {
  const { t } = useTranslation();
  const id = useId();
  const [open, setOpen] = useState(false);
  const [query, setQuery] = useState('');
  const [active, setActive] = useState(0);
  const q = useDebounced(query.trim(), 250);
  const options = useTaskAssignees(q, open);
  const users = options.data?.users ?? [];
  const teams = options.data?.teams ?? [];
  const choices: AssigneeChoice[] = [
    ...users.map((u) => ({ type: 'user' as const, id: u.id, name: u.fullName })),
    ...teams.map((tm) => ({ type: 'team' as const, id: tm.id, name: tm.name })),
  ];
  const details = [...users.map((u) => u.jobTitle), ...teams.map((tm) => t('tasks.picker.members', { count: tm.memberCount }))];
  const optionId = (i: number) => `${id}-option-${i}`;

  const pick = (c: AssigneeChoice) => {
    onChange(c);
    setQuery('');
    setOpen(false);
  };

  const option = (c: AssigneeChoice, i: number) => (
    <div
      key={`${c.type}-${c.id}`}
      id={optionId(i)}
      role="option"
      aria-label={c.name}
      aria-selected={value?.type === c.type && value.id === c.id}
      // Keep the focus in the input, so its blur does not close the list before the click lands.
      onMouseDown={(e) => e.preventDefault()}
      onClick={() => pick(c)}
      className={cn('flex cursor-pointer items-center justify-between gap-3 rounded-sm px-2 py-1.5 text-sm', i === active ? 'bg-accent' : 'hover:bg-accent/60')}
    >
      <span>{c.name}</span>
      {details[i] && <span className="text-muted-foreground text-xs">{details[i]}</span>}
    </div>
  );

  return (
    <div className="relative grid gap-1.5">
      <Label htmlFor={id}>{label}</Label>
      <div className="flex items-center gap-2">
        <Input
          id={id}
          role="combobox"
          autoComplete="off"
          aria-expanded={open}
          aria-controls={`${id}-list`}
          aria-autocomplete="list"
          aria-activedescendant={open && choices[active] ? optionId(active) : undefined}
          placeholder={t('tasks.picker.placeholder')}
          value={open ? query : (value?.name ?? '')}
          onFocus={() => setOpen(true)}
          onClick={() => setOpen(true)}
          onBlur={() => setOpen(false)}
          onChange={(e) => {
            setQuery(e.target.value);
            setActive(0);
            setOpen(true);
          }}
          onKeyDown={(e) => {
            if (e.key === 'ArrowDown' || e.key === 'ArrowUp') {
              e.preventDefault();
              setOpen(true);
              const step = e.key === 'ArrowDown' ? 1 : -1;
              setActive((i) => Math.max(0, Math.min(choices.length - 1, i + step)));
            } else if (e.key === 'Enter' && open && choices[active]) {
              e.preventDefault();
              pick(choices[active]);
            }
          }}
        />
        {clearable && value && (
          <Button type="button" variant="ghost" size="sm" onClick={() => onChange(null)}>
            {t('tasks.picker.clear')}
          </Button>
        )}
      </div>
      {open && (
        <div
          id={`${id}-list`}
          role="listbox"
          aria-label={label}
          className="bg-popover text-popover-foreground absolute top-full z-50 mt-1 grid max-h-64 w-full gap-2 overflow-y-auto rounded-md border p-1 shadow-md"
        >
          {options.isPending && <p className="text-muted-foreground px-2 py-1.5 text-sm">{t('common.loading')}</p>}
          {options.isError && <p className="text-destructive px-2 py-1.5 text-sm">{errorText(t, options.error)}</p>}
          {options.isSuccess && choices.length === 0 && <p className="text-muted-foreground px-2 py-1.5 text-sm">{t('common.noResults')}</p>}
          {users.length > 0 && (
            <div role="group" aria-label={t('tasks.picker.people')}>
              <p aria-hidden className="text-muted-foreground px-2 py-1 text-xs font-medium">
                {t('tasks.picker.people')}
              </p>
              {choices.slice(0, users.length).map((c, i) => option(c, i))}
            </div>
          )}
          {teams.length > 0 && (
            <div role="group" aria-label={t('tasks.picker.teams')}>
              <p aria-hidden className="text-muted-foreground px-2 py-1 text-xs font-medium">
                {t('tasks.picker.teams')}
              </p>
              {choices.slice(users.length).map((c, i) => option(c, users.length + i))}
            </div>
          )}
        </div>
      )}
    </div>
  );
}

import {
  type CreateTaskInput,
  DEFAULT_TASK_EVIDENCE,
  type ProblemDto,
  TASK_LIMITS,
  type TaskAssignee,
  type TaskDetail,
  type TaskEvidence,
  type TaskPriority,
  type UpdateTaskInput,
} from '@taskop/contracts';
import { type AssigneeChoice, dueAtFromLocal, localDueParts, sameChoice } from './labels';

export interface TaskFormValues {
  title: string;
  instructions: string;
  priority: TaskPriority;
  assignee: AssigneeChoice | null;
  siteId: string;
  /** Tenant-local YYYY-MM-DD and HH:MM, or ''. */
  dueDate: string;
  dueTime: string;
  requiresReview: boolean;
  evidence: TaskEvidence;
}

/** i18n keys per field. */
export type TaskFormErrors = Partial<Record<'title' | 'assignee' | 'dueDate', string>>;

const EVIDENCE_KEYS = ['photo', 'video', 'liveOnly'] as const;

/** The picker's value for a task: its person if someone holds it, else its team. */
export const choiceOf = (t: Pick<TaskDetail, 'assignee' | 'team'>): AssigneeChoice | null =>
  t.assignee ? { type: 'user', id: t.assignee.id, name: t.assignee.fullName } : t.team ? { type: 'team', id: t.team.id, name: t.team.name } : null;

export const toAssignee = (c: AssigneeChoice): TaskAssignee => (c.type === 'user' ? { userId: c.id } : { teamId: c.id });

/** Spec §8 pre-fill from a problem: title = item label, instructions = note, high for critical, review on. */
export function initialValues(source: { task?: TaskDetail; problem?: ProblemDto }, timeZone: string): TaskFormValues {
  const { task, problem } = source;
  if (task) {
    const due = localDueParts(task.dueAt, timeZone);
    return {
      title: task.title,
      instructions: task.instructions,
      priority: task.priority,
      assignee: choiceOf(task),
      siteId: task.site?.id ?? '',
      dueDate: due.date,
      dueTime: due.time,
      requiresReview: task.requiresReview,
      evidence: { ...task.evidence },
    };
  }
  return {
    title: problem?.itemLabel ?? '',
    instructions: problem?.note ?? '',
    priority: problem?.severity === 'critical' ? 'high' : 'normal',
    assignee: null,
    siteId: problem?.siteId ?? '',
    dueDate: '',
    dueTime: '',
    requiresReview: Boolean(problem),
    evidence: { ...DEFAULT_TASK_EVIDENCE },
  };
}

export function formErrors(v: TaskFormValues): TaskFormErrors {
  const errors: TaskFormErrors = {};
  const title = v.title.trim();
  if (!title) errors.title = 'errors.validation.required';
  else if (title.length > TASK_LIMITS.titleMax) errors.title = 'errors.validation.tooLong';
  if (!v.assignee) errors.assignee = 'errors.validation.required';
  if (v.dueTime && !v.dueDate) errors.dueDate = 'tasks.dialog.dateRequired';
  return errors;
}

/** API field errors (i18n keys) on the dialog's fields. */
export const fieldErrors = (fields: Record<string, string>): TaskFormErrors => ({
  ...(fields.title ? { title: fields.title } : {}),
  ...(fields.assignee ? { assignee: fields.assignee } : {}),
  ...(fields.dueAt ? { dueDate: fields.dueAt } : {}),
});

/** POST /tasks. A problem's site is the API's to take (Part 1 decision 19), so none is sent with one. */
export function createBody(id: string, v: TaskFormValues, timeZone: string, problem?: ProblemDto): CreateTaskInput {
  return {
    id,
    title: v.title.trim(),
    instructions: v.instructions.trim(),
    priority: v.priority,
    siteId: problem ? null : v.siteId || null,
    dueAt: dueAtFromLocal(v.dueDate, v.dueTime, timeZone),
    evidence: v.evidence,
    requiresReview: v.requiresReview,
    assignee: toAssignee(v.assignee!),
    problemId: problem?.id ?? null,
  };
}

/**
 * PATCH /tasks/:id with only what changed: a stale form never overwrites someone else's edit, and the assignee is
 * sent (a reassign, back to `new`) only when another person or team was picked.
 */
export function changedFields(task: TaskDetail, v: TaskFormValues, timeZone: string): UpdateTaskInput {
  const before = initialValues({ task }, timeZone);
  const body: UpdateTaskInput = {};
  if (v.title.trim() !== before.title) body.title = v.title.trim();
  if (v.instructions.trim() !== before.instructions) body.instructions = v.instructions.trim();
  if (v.priority !== before.priority) body.priority = v.priority;
  if (task.source === 'adhoc' && v.siteId !== before.siteId) body.siteId = v.siteId || null;
  if (v.dueDate !== before.dueDate || v.dueTime !== before.dueTime) body.dueAt = dueAtFromLocal(v.dueDate, v.dueTime, timeZone);
  if (v.requiresReview !== before.requiresReview) body.requiresReview = v.requiresReview;
  if (EVIDENCE_KEYS.some((k) => v.evidence[k] !== before.evidence[k])) body.evidence = v.evidence;
  if (v.assignee && !sameChoice(v.assignee, before.assignee)) body.assignee = toAssignee(v.assignee);
  return body;
}

import { ApiError } from '@taskop/api-client';
import {
  EVIDENCE_LEVELS,
  type EvidenceLevel,
  MEDIA_LIMITS,
  type ProblemDto,
  TASK_LIMITS,
  TASK_PRIORITIES,
  type TaskDetail,
  type TaskPriority,
} from '@taskop/contracts';
import { useQueryClient } from '@tanstack/react-query';
import { useState } from 'react';
import { useTranslation } from 'react-i18next';
import { toast } from 'sonner';
import { FormError } from '@/components/form-error';
import { NativeSelect } from '@/components/native-select';
import { Button } from '@/components/ui/button';
import { Checkbox } from '@/components/ui/checkbox';
import { Dialog, DialogContent, DialogDescription, DialogFooter, DialogHeader, DialogTitle } from '@/components/ui/dialog';
import { Input } from '@/components/ui/input';
import { Label } from '@/components/ui/label';
import { Textarea } from '@/components/ui/textarea';
import { formatLocalDate } from '@/features/scheduling/labels';
import { useSites } from '@/features/sites/queries';
import { errorText } from '@/lib/errors';
import { uuidv7 } from '@/lib/ids';
import { api, useMe } from '@/lib/session';
import { AssigneePicker } from './assignee-picker';
import { sameChoice } from './labels';
import { type PendingMedia, prepareFiles, type ReadMediaMeta, readMediaMeta, uploadInstructionMedia } from './media-files';
import { storeTask, taskKeys } from './queries';
import { changedFields, choiceOf, createBody, fieldErrors, formErrors, initialValues, type TaskFormErrors, type TaskFormValues } from './task-form';

const ACCEPT = [...MEDIA_LIMITS.mimeTypes.photo, ...MEDIA_LIMITS.mimeTypes.video].join(',');

interface Props {
  /** Edit this task; without it the dialog creates one. */
  task?: TaskDetail;
  /** Create the fix for this closed run's problem (spec §8): pre-filled, its site, review on. */
  problem?: ProblemDto;
  onClose: () => void;
  /** The created or saved task, also when the dialog is closed after a failed upload. */
  onSaved?: (task: TaskDetail) => void;
  /** Injected by tests: jsdom cannot decode images or videos. */
  readMeta?: ReadMediaMeta;
}

export function TaskDialog({ task, problem, onClose, onSaved, readMeta = readMediaMeta }: Props) {
  const { t } = useTranslation();
  const qc = useQueryClient();
  const { tenant } = useMe();
  // A problem task's site comes from the problem (Part 1 decision 19): shown, never edited.
  const fixedSite = problem ? problem.siteName : task?.source === 'problem' ? (task.site?.name ?? '—') : null;
  const sites = useSites(fixedSite === null);
  const [values, setValues] = useState<TaskFormValues>(() => initialValues({ task, problem }, tenant.timezone));
  const [errors, setErrors] = useState<TaskFormErrors>({});
  const [files, setFiles] = useState<PendingMedia[]>([]);
  const [saved, setSaved] = useState<TaskDetail | null>(null);
  const [newId] = useState(() => uuidv7());
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const set = <K extends keyof TaskFormValues>(key: K, value: TaskFormValues[K]) => setValues((v) => ({ ...v, [key]: value }));
  const patchFile = (id: string, patch: Partial<PendingMedia>) => setFiles((fs) => fs.map((f) => (f.id === id ? { ...f, ...patch } : f)));
  const existing = task?.media.filter((m) => m.role === 'instruction').length ?? 0;
  const room = TASK_LIMITS.instructionMedia - existing - files.filter((f) => f.state !== 'refused').length;
  const reassigning = task !== undefined && values.assignee !== null && !sameChoice(values.assignee, choiceOf(task));
  const visibleSites = (sites.data ?? []).filter((s) => s.active || s.id === values.siteId);

  const close = () => {
    if (saved) onSaved?.(saved);
    onClose();
  };

  const addFiles = async (list: File[]) => {
    const next = await prepareFiles(list, room, readMeta);
    setFiles((fs) => [...fs, ...next]);
  };

  const submit = async () => {
    const found = saved ? {} : formErrors(values);
    setErrors(found);
    if (Object.keys(found).length) return;
    setBusy(true);
    setError(null);
    try {
      let current = saved;
      if (!current) {
        if (task) {
          const body = changedFields(task, values, tenant.timezone);
          current = Object.keys(body).length ? await api.tasks.update(task.id, body) : task;
        } else {
          current = await api.tasks.create(createBody(newId, values, tenant.timezone, problem));
        }
        setSaved(current);
      }
      // The task exists now: a failed file is retried with the same id, never with a second task.
      const failed = await uploadInstructionMedia(current.id, files, patchFile);
      await storeTask(qc, current);
      if (files.some((f) => f.state !== 'refused')) await qc.invalidateQueries({ queryKey: taskKeys.detail(current.id) });
      if (failed > 0) {
        setError(t('tasks.dialog.uploadFailed', { count: failed }));
        return;
      }
      toast.success(t(task ? 'tasks.dialog.saved' : 'tasks.dialog.created'));
      onSaved?.(current);
      onClose();
    } catch (e) {
      setError(errorText(t, e));
      if (e instanceof ApiError) {
        if (e.fields) setErrors(fieldErrors(e.fields));
        // Someone else made the task first: let the problems page show it.
        if (e.code === 'PROBLEM_ALREADY_HAS_TASK') void qc.invalidateQueries({ queryKey: ['problems'] });
      }
    } finally {
      setBusy(false);
    }
  };

  const fieldError = (key: keyof TaskFormErrors) => {
    const message = errors[key];
    return message ? <p className="text-destructive text-sm">{t(message)}</p> : null;
  };

  return (
    <Dialog open onOpenChange={(open) => !open && close()}>
      <DialogContent className="max-h-[90vh] overflow-y-auto sm:max-w-2xl">
        <DialogHeader>
          <DialogTitle>{t(task ? 'tasks.dialog.editTitle' : problem ? 'tasks.dialog.fromProblem' : 'tasks.dialog.createTitle')}</DialogTitle>
          <DialogDescription>{problem ? `${problem.checklistName} · ${formatLocalDate(problem.localDate)}` : t('tasks.dialog.description')}</DialogDescription>
        </DialogHeader>
        <div className="grid gap-4">
          <div className="grid gap-1.5">
            <Label htmlFor="task-title">{t('tasks.dialog.title')}</Label>
            <Input
              id="task-title"
              value={values.title}
              maxLength={TASK_LIMITS.titleMax}
              aria-invalid={Boolean(errors.title)}
              onChange={(e) => set('title', e.target.value)}
            />
            {fieldError('title')}
          </div>
          <div className="grid gap-1.5">
            <Label htmlFor="task-instructions">{t('tasks.dialog.instructions')}</Label>
            <Textarea
              id="task-instructions"
              value={values.instructions}
              maxLength={TASK_LIMITS.instructionsMax}
              onChange={(e) => set('instructions', e.target.value)}
            />
          </div>
          <div className="grid gap-4 sm:grid-cols-2">
            <div className="grid gap-1.5">
              <Label htmlFor="task-priority">{t('tasks.dialog.priority')}</Label>
              <NativeSelect id="task-priority" value={values.priority} onChange={(e) => set('priority', e.target.value as TaskPriority)}>
                {TASK_PRIORITIES.map((p) => (
                  <option key={p} value={p}>
                    {t(`tasks.priorities.${p}`)}
                  </option>
                ))}
              </NativeSelect>
            </div>
            <div className="grid gap-1.5">
              {fixedSite !== null ? (
                <>
                  <span className="text-sm font-medium">{t('tasks.dialog.site')}</span>
                  <p className="text-sm">{t('tasks.dialog.siteFromProblem', { site: fixedSite })}</p>
                </>
              ) : (
                <>
                  <Label htmlFor="task-site">{t('tasks.dialog.site')}</Label>
                  <NativeSelect id="task-site" value={values.siteId} onChange={(e) => set('siteId', e.target.value)}>
                    <option value="">{t('tasks.dialog.noSite')}</option>
                    {visibleSites.map((s) => (
                      <option key={s.id} value={s.id}>
                        {s.name}
                      </option>
                    ))}
                  </NativeSelect>
                </>
              )}
            </div>
          </div>
          <div className="grid gap-1.5">
            <AssigneePicker label={t('tasks.dialog.assignee')} value={values.assignee} onChange={(c) => set('assignee', c)} />
            {fieldError('assignee')}
            {reassigning && <p className="text-muted-foreground text-sm">{t('tasks.dialog.reassignNote')}</p>}
          </div>
          <div className="grid gap-1.5">
            <div className="flex flex-wrap gap-3">
              <div className="grid gap-1.5">
                <Label htmlFor="task-due-date">{t('tasks.dialog.dueDate')}</Label>
                <Input id="task-due-date" type="date" value={values.dueDate} onChange={(e) => set('dueDate', e.target.value)} className="w-44" />
              </div>
              <div className="grid gap-1.5">
                <Label htmlFor="task-due-time">{t('tasks.dialog.dueTime')}</Label>
                <Input id="task-due-time" type="time" value={values.dueTime} onChange={(e) => set('dueTime', e.target.value)} className="w-32" />
              </div>
            </div>
            <p className="text-muted-foreground text-xs">{t('tasks.dialog.dueHint', { timeZone: tenant.timezone })}</p>
            {fieldError('dueDate')}
          </div>
          <div className="flex items-center gap-2">
            <Checkbox id="task-review" checked={values.requiresReview} onCheckedChange={(c) => set('requiresReview', c === true)} />
            <Label htmlFor="task-review" className="font-normal">

                    {f.error && <span className="text-destructive">{t(f.error, { count: TASK_LIMITS.instructionMedia })}</span>}
                    {(f.state === 'waiting' || f.state === 'failed' || f.state === 'refused') && (
                      <Button type="button" variant="ghost" size="sm" disabled={busy} onClick={() => setFiles((fs) => fs.filter((x) => x.id !== f.id))}>

                      </Button>
                    )}
                  </li>
                ))}
              </ul>
            )}
          </div>
          <FormError message={error} />
        </div>

          <Button variant="outline" onClick={close}>
            {t('common.cancel')}
          </Button>
          <Button disabled={busy} onClick={() => void submit()}>
            {saved ? t('tasks.dialog.retryUpload') : t(task ? 'common.save' : 'common.create')}
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}

/** The task drawer (spec §8), opened by `/tasks?task=<id>`. What the caller may do comes from canManage / canReview. */
export function TaskDrawer({ id, onClose }: { id: string; onClose: () => void }) {
  const { t } = useTranslation();
  const formatDateTime = useFormatDateTime();
  const task = useTask(id);
  const [editing, setEditing] = useState(false);
  // Kept here, not in the actions: a refused action may refetch a task whose actions then disappear.
  const [actionError, setActionError] = useState<string | null>(null);
  const d = task.data;

  return (
    <Dialog open onOpenChange={(open) => !open && onClose()}>
      <DialogContent className="max-h-[90vh] overflow-y-auto sm:max-w-3xl">
        <DialogHeader>
          <DialogTitle>{d?.title ?? (task.isError ? t('tasks.drawer.title') : t('common.loading'))}</DialogTitle>
          {d && <DialogDescription>{t('tasks.drawer.createdBy', { name: d.createdBy.fullName, time: formatDateTime(d.createdAt) })}</DialogDescription>}
        </DialogHeader>
        {task.isError && <p className="text-destructive text-sm">{errorText(t, task.error)}</p>}
        <FormError message={actionError} />
        {d && <TaskBody task={d} onEdit={() => setEditing(true)} onError={setActionError} />}
        {editing && d && <TaskDialog task={d} onClose={() => setEditing(false)} />}
        <DialogFooter>
          <Button variant="outline" onClick={onClose}>
            {t('common.close')}
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}

function Actions({ task, onEdit, onError }: { task: TaskDetail; onEdit: () => void; onError: (message: string | null) => void }) {
  const { t } = useTranslation();
  const qc = useQueryClient();
  const [comment, setComment] = useState('');
  const [reason, setReason] = useState('');
  const [busy, setBusy] = useState(false);
  const decide = task.canReview && task.status === 'awaiting_review';
  const change = task.canManage && !isFinalTaskStatus(task.status);
  if (!decide && !change) return null;

  const run = async (command: () => Promise<TaskDetail>, done: string) => {
    setBusy(true);
    onError(null);
    try {
      await storeTask(qc, await command());
      setComment('');
      setReason('');
      toast.success(t(done));
    } catch (e) {
      onError(errorText(t, e));
      // Someone else moved the task meanwhile (a new submission, another reviewer, a cancel): show it as it is now.
      if (e instanceof ApiError && e.status === 409) await qc.invalidateQueries({ queryKey: taskKeys.detail(task.id) });
    } finally {
      setBusy(false);
    }
  };

  return (

            {t('tasks.drawer.approve')}
          </Button>
          <Label htmlFor="task-reject-comment">{t('tasks.drawer.rejectComment')}</Label>
          <Textarea id="task-reject-comment" value={comment} maxLength={TASK_LIMITS.commentMax} onChange={(e) => setComment(e.target.value)} />
          <Button
            variant="outline"
            className="w-fit"
            disabled={busy || !comment.trim()}
            onClick={() => void run(() => api.tasks.review(task.id, { decision: 'reject', comment: comment.trim() }), 'tasks.drawer.rejected')}
          >
            {t('tasks.drawer.reject')}
          </Button>
        </div>
      )}
      {change && (
        <div className="grid gap-2">
          <Button variant="outline" className="w-fit" onClick={onEdit}>
            {t('common.edit')}
          </Button>
          <Label htmlFor="task-cancel-reason">{t('tasks.drawer.cancelLabel')}</Label>
          <Textarea id="task-cancel-reason" value={reason} maxLength={TASK_LIMITS.commentMax} onChange={(e) => setReason(e.target.value)} />

            variant="destructive"
            className="w-fit"

/** UUIDv7 (RFC 9562): 48-bit Unix ms, version 7, variant 10, random rest. The phone generates IDs like this. */
function uuidv7(): string {
  const b = randomBytes(16);
  const ms = BigInt(Date.now());
  for (let i = 0; i < 6; i++) b[i] = Number((ms >> BigInt(8 * (5 - i))) & 0xffn);
  b[6] = (b[6]! & 0x0f) | 0x70;
  b[8] = (b[8]! & 0x3f) | 0x80;
  const h = b.toString('hex');
  return `${h.slice(0, 8)}-${h.slice(8, 12)}-${h.slice(12, 16)}-${h.slice(16, 20)}-${h.slice(20)}`;
}

/** The tenant's local date (new tenants are in Asia/Baku, which has no DST). */
const bakuDate = (at: Date): string =>
  new Intl.DateTimeFormat('en-CA', { timeZone: 'Asia/Baku', year: 'numeric', month: '2-digit', day: '2-digit' }).format(at);

function apiAs(request: APIRequestContext, accessToken: string) {
  const headers = { Authorization: `Bearer ${accessToken}` };
  return async function call<T = unknown>(method: string, url: string, data?: unknown): Promise<T> {
    const res = await request.fetch(`/api/v1${url}`, { method, headers, data });
    expect(res.ok(), `${method} ${url}: ${await res.text()}`).toBeTruthy();
    return (res.status() === 204 ? null : await res.json()) as T;
  };
}

  await phone('POST', '/executions', {
    id: executionId,
    occurrenceId: occurrence.id,
    startedAt: new Date().toISOString(),
    device: { platform: 'android', osVersion: '15', appVersion: '1.0.0' },
    ...stamp(),
  });
  const photoItem = item('Ümumi görünüşün fotosu');
  const photoId = uuidv7();
  await phone('POST', `/executions/${executionId}/media`, {
    id: photoId,
    itemId: photoItem.id,
    kind: 'photo',
    source: 'camera',
    mime: 'image/jpeg',
    bytes: 1000,
    width: 1600,
    height: 1200,
    capturedAt: new Date().toISOString(),
    ...stamp(),
  });
  const answers: Record<string, Record<string, unknown>> = {};
  for (const i of items) {
    // "Zibil qutuları boşaldılıb?" = Xeyr is a rule problem (normal). "Pis qoxu var?" = Xeyr is the good answer.
    if (i.type === 'yes_no') {
      answers[i.id] = { optionIds: [['Zibil qutuları boşaldılıb?', 'Pis qoxu var?'].includes(i.label) ? i.options[1].id : i.options[0].id] };
    }
    if (i.type === 'single_choice') answers[i.id] = { optionIds: [i.options[0]!.id] };
  }
  answers[photoItem.id] = { photos: [photoId] };
  const glass = item('Giriş qapısının şüşələri təmizdir?');
  answers[glass.id] = { ...answers[glass.id], problem: { severity: 'critical', note: 'Şüşədə çat var', mediaIds: [] } };
  await phone('PUT', `/executions/${executionId}/answers`, { rev: 1, answers, ...stamp() });
  const completed = await phone('POST', `/executions/${executionId}/complete`, { rev: 2, answers, completedAt: new Date().toISOString(), ...stamp() });
  expect(completed).toMatchObject({ state: 'completed' });

  // The owner on the web turns the glass problem into a task.
  await page.goto('/login');
  await page.getByLabel('E-poçt', { exact: true }).fill(email);
  await page.getByLabel('Şifrə', { exact: true }).fill(password);
  await page.getByRole('button', { name: 'Daxil ol' }).click();
  await page.getByRole('link', { name: 'Problemlər' }).click();
  const glassRow = page.getByRole('row').filter({ hasText: 'Şüşədə çat var' });
  await glassRow.getByRole('button', { name: 'Tapşırıq yarat' }).click();

  const dialog = page.getByRole('dialog', { name: 'Problemdən tapşırıq' });
  await expect(dialog.getByLabel('Başlıq', { exact: true })).toHaveValue('Giriş qapısının şüşələri təmizdir?');
  await expect(dialog.getByLabel('Təlimat', { exact: true })).toHaveValue('Şüşədə çat var');
  await expect(dialog.getByLabel('Prioritet', { exact: true })).toHaveValue('high');
  await expect(dialog.getByRole('checkbox', { name: 'Tamamlandıqdan sonra yoxlama tələb olunur' })).toBeChecked();
  await expect(dialog.getByText('Obyekt problemdən götürülür: Anbar №1')).toBeVisible();
  await dialog.getByRole('combobox', { name: 'İcraçı', exact: true }).fill('Nigar');
  await dialog.getByRole('option', { name: 'Nigar Səfərli' }).click();
  await dialog.getByRole('button', { name: 'Yarat', exact: true }).click();
  await expect(dialog).toBeHidden();
  await expect(glassRow.getByRole('link', { name: 'Açıq' })).toBeVisible();

  // The phone: the task arrives with the next sync; start and answer (no evidence is required by default).
  const taskSync = await phone<SyncResponse>('GET', '/me/sync');
  expect(taskSync.tasks).toHaveLength(1);
  const task = taskSync.tasks[0]!;
  expect(task).toMatchObject({ status: 'new', title: 'Giriş qapısının şüşələri təmizdir?', priority: 'high', requiresReview: true, site: { name: 'Anbar №1' } });
  await phone('POST', `/tasks/${task.id}/start`, { at: new Date().toISOString() });
  const first = await phone<TaskDetail>('POST', `/tasks/${task.id}/submissions`, {
    id: uuidv7(),
    text: 'Şüşə dəyişdirildi',
    mediaIds: [],
    submittedAt: new Date().toISOString(),
  });
  expect(first.status).toBe('awaiting_review');

  // The manager sends it back from the drawer.
  await glassRow.getByRole('link', { name: 'Açıq' }).click();
  await expect(page).toHaveURL(new RegExp(`/tasks\\?task=${task.id}`));
  const drawer = page.getByRole('dialog', { name: 'Giriş qapısının şüşələri təmizdir?' });
  await expect(drawer.getByText('Yoxlamada', { exact: true })).toBeVisible();
  await expect(drawer.getByRole('listitem', { name: 'Cavab 1' })).toContainText('Şüşə dəyişdirildi');
  await expect(drawer.getByRole('region', { name: 'Mənbə problem' })).toContainText('Şüşədə çat var');
  await drawer.getByLabel('Geri qaytarma səbəbi').fill('Qırıq şüşənin qalıqlarını da yığın');
  await drawer.getByRole('button', { name: 'Geri qaytar' }).click();
  await expect(drawer.getByText('İcradadır', { exact: true })).toBeVisible();
  await expect(drawer.getByRole('listitem', { name: 'Cavab 1' })).toContainText('Geri qaytarılıb');

  // The phone answers again.
  const second = await phone<TaskDetail>('POST', `/tasks/${task.id}/submissions`, {
    id: uuidv7(),
    text: 'Qalıqlar yığıldı',
    mediaIds: [],
    submittedAt: new Date().toISOString(),
  });
  expect(second.status).toBe('awaiting_review');

  // The drawer is a link: a reload opens it again with the new answer; the manager approves.
  await page.reload();
  await expect(drawer.getByRole('listitem', { name: 'Cavab 2' })).toContainText('Qalıqlar yığıldı');
  await drawer.getByRole('button', { name: 'Təsdiqlə' }).click();
  await expect(drawer.getByText('Tamamlanıb', { exact: true })).toBeVisible();
  await expect(drawer.getByRole('listitem', { name: 'Cavab 2' })).toContainText('Təsdiqlənib');
  await expect(drawer.getByRole('region', { name: 'Tarixçə' })).toContainText('Yoxlamada → Tamamlanıb');

  // The task list, then the problem: resolved.
  await drawer.getByRole('button', { name: 'Bağla', exact: true }).click();
  const taskRow = page.getByRole('row').filter({ hasText: 'Giriş qapısının şüşələri təmizdir?' });
  for (const text of ['Tamamlanıb', 'Nigar Səfərli', 'Anbar №1', 'Problemdən']) await expect(taskRow).toContainText(text);
  await page.getByRole('link', { name: 'Problemlər' }).click();
  await expect(page.getByRole('row').filter({ hasText: 'Şüşədə çat var' }).getByRole('link', { name: 'Həll olunub' })).toBeVisible();
});
